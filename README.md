# Бот-консультант — валидация и квалификация лидов

Тестовое задание: Telegram-бот, который ведёт диалог с потенциальным клиентом,
задаёт квалифицирующие вопросы, определяет целевой лид или нет, и либо
предлагает следующий шаг (звонок/встреча), либо вежливо закрывает нецелевой диалог.

Бот сделан **универсальным**: под конкретную нишу (недвижимость, авто, услуги и т.п.)
он адаптируется через `config.py` — тексты вопросов, варианты ответов и веса скоринга,
без изменения логики в `bot.py`.

## Сценарий диалога (дерево)

```
/start
  └─ Приветствие + открытый вопрос о потребности
       └─ [ответ: свободный текст]
            └─ Вопрос про бюджет (кнопки с диапазонами)
                 └─ [выбор варианта]
                      └─ Вопрос про сроки (кнопки со сроками)
                           └─ [выбор варианта]
                                ├─ РАСЧЁТ СКОРИНГА (бюджет + сроки)
                                │
                                ├─ score >= порога → ЦЕЛЕВОЙ ЛИД
                                │     └─ Сообщение с предложением созвона
                                │          └─ Запрос контакта (телефон/мессенджер + удобное время)
                                │               └─ Благодарность, конец диалога
                                │
                                └─ score < порога → НЕЦЕЛЕВОЙ ЛИД
                                      └─ Вежливое закрытие диалога, подсказка написать позже
```

`/cancel` — прерывает диалог на любом шаге.

## Логика квалификации

Простая скоринговая модель в `config.py` → `QUALIFICATION_RULES`:

- каждому варианту ответа на "бюджет" и "сроки" присвоен вес (0–3);
- сумма весов сравнивается с порогом `QUALIFY_THRESHOLD` (по умолчанию 3 из 6 максимума);
- если сумма ≥ порога — лид считается целевым.

Пороги и веса — просто числа в конфиге, подстраиваются под нишу без правки кода.

## Как адаптировать под другую нишу

Откройте `config.py` и замените:

- `NICHE["greeting"]`, `NICHE["budget_options"]`, `NICHE["timeline_options"]` — под тематику
  (например, для авто: "До 500 000 ₽ / 500 000–1 500 000 ₽ / Более 1 500 000 ₽");
- `QUALIFICATION_RULES` — веса и порог квалификации под ожидаемые чеки в нише.

Код бота (`bot.py`) при этом не меняется.

## Запуск

1. Установить зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Получить токен бота у [@BotFather](https://t.me/BotFather) (`/newbot`).
3. Скопировать `.env.example` в `.env` и вписать токен:
   ```
   BOT_TOKEN=123456:ABC-...
   ```
4. Запустить:
   ```
   python bot.py
   ```
5. Написать боту `/start` в Telegram.

## Что не входит (по ТЗ тестового)

- интеграция с реальными данными/CRM;
- платёжные и банковские сценарии;
- хранение лидов в базе данных — сейчас данные лида логируются в консоль
  (`logger.info(...)` в `bot.py`), для прод-версии легко подключить БД или Google Sheets.
